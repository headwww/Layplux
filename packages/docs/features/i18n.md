# 国际化

Layplux 通过 `provide/inject` 下发语言包，零依赖。

## 切换语言

```ts
skeleton.setLocale('en-US')
```

内置 `zh-CN`（默认）和 `en-US`。

## 自定义语言

```ts
skeleton.locale.value = {
  panel: {
    viewMode: 'View Mode',
    dockPinned: 'Dock Pinned',
    dockUnpinned: 'Dock Unpinned',
    undock: 'Undock',
    help: 'Help',
    more: 'More',
    minimize: 'Minimize',
  },
}
```

## 语言包结构

```ts
interface LaypluxLocale {
  panel: {
    viewMode: string
    dockPinned: string
    dockUnpinned: string
    undock: string
    help: string
    more: string
    minimize: string
  }
}
```

## 工作原理

```
ISkeleton.locale (Ref<LaypluxLocale>)
       │
  RootPane: provide('layplux-locale', locale)
       │
  PanelView: inject('layplux-locale')
       │
  locale.value.panel.viewMode → 渲染对应语言文案
```
